# Progress Tracker

Tick a module **only** when its `Done when` list is fully cleared. A tracker you have lied to
is worse than no tracker at all.

Run `python3 scripts/progress.py` for a completion summary, or `--next` for today's assignment.

Each module has three passes — see [`docs/00-orientation/study-method.md`](../docs/00-orientation/study-method.md).

| Legend | Meaning |
| --- | --- |
| `P1` | **Encode** — worked through the module on its scheduled day |
| `P2` | **Retrieve** — self-check answered cold, 3–7 days later |
| `P3` | **Consolidate** — weak-area entries closed out in the revision phase |
