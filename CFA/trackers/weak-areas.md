# Weak Areas Log

**This is the highest-value file in the repository by month 4.** Everything you get wrong goes here,
categorised — because the four categories have four completely different remedies.

## The categories

| Code | Meaning | The fix |
| --- | --- | --- |
| **K** | **Knowledge gap** — didn't know it | Back to the module |
| **A** | **Application error** — knew it, misapplied it | More questions on that specific LOS |
| **C** | **Careless** — misread the stem, wrong sign, wrong units, stale calculator register | A **process** fix, not a study fix |
| **T** | **Time** — guessed because the clock ran out | A **pacing** fix |

> **Lumping these together as "I got it wrong" is how candidates re-study material they already know
> while never fixing their actual problem.** If most of your misses are **C**, more studying will not
> help — slowing down on the stem will.

## How to use it

1. **Log every miss, the same day.** A miss you did not write down is a miss you will repeat
2. **Categorise honestly.** "C" is uncomfortable to write and is usually the right code
3. **Write the fix, not just the error.** "Forgot to double the semiannual I/Y" is useful;
   "Fixed Income is hard" is not
4. **Re-test.** An entry is not closed until you have answered a similar question correctly, cold
5. **Review weekly, not just append.** On the Sunday light day, read the open entries and look for
   the pattern
