## Why this order

**Financial Statement Analysis first.** It is the language the rest of the exam speaks. Equity
valuation needs FCFF; credit analysis needs coverage ratios; Corporate Issuers needs ROIC. Learning
FSA first means every later topic reinforces it instead of waiting on it.

**Quantitative Methods split in two.** The first five modules (rates and returns, time value,
statistical measures, probability) are tools you need from day 21 onwards. The last six
(sampling, hypothesis testing, regression, machine learning, big data) stand alone and are better
placed at the end, where they double as a fresh-material block while everything else consolidates.

**Ethics runs the whole way through.** It is the heaviest single weight on the exam (15–20%) and
the one topic that rewards repeated short exposure over a single block. Ten hours a fortnight for
five months beats a 150-hour sprint, and the Standards only become automatic with spacing.

**Fixed Income before Derivatives.** Discounting, spot and forward rates, and duration all come
from Fixed Income; Derivatives assumes them. Doing Derivatives first means learning the same
mathematics twice.

**Derivatives before Alternatives.** Alternative Investments leans on futures pricing for
commodity roll return — contango, backwardation, and why long-only commodity index returns lag
spot. That is a Derivatives result.

## What a module looks like

Every one of the 102 modules has the same seven sections:

1. **At a glance** — hours, prerequisites, where it appears on the exam
2. **Learning Outcome Statements** — verbatim from the 2027 CFA Institute outline
3. **Core concepts** — the actual teaching
4. **Formulas to know cold** — nothing optional in this list
5. **Exam traps** — the specific mistakes this material invites
6. **Self-check** — questions with folded answers
7. **Done when** — the checklist that decides whether you move on

Read §1 and §2, work §3, memorise §4, read §5, then answer §6 **without looking back**. If you
cannot, the module is not done, whatever the clock says.
