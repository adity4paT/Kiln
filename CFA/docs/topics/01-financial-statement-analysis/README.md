# Financial Statement Analysis

*The prerequisite topic that isn't labelled as one.*

| | |
| --- | --- |
| **Exam weight** | 11-14% — roughly 19–25 of 180 questions |
| **Study block** | Month 1, days 1–20 |
| **Budget** | 20 days · 80 hours |
| **Modules** | 12 |
| **Position in study order** | 1 of 10 |

## Why this topic sits here

FSA is studied **first**, ahead of everything including Quantitative Methods, and that is a
deliberate departure from the order the curriculum prints in.

Three other topics quietly assume you can read a financial statement:

- **Equity Investments** asks you to forecast financial statements and value the result.
- **Corporate Issuers** asks you to compute a cash conversion cycle, an NPV, and a WACC from
  reported figures.
- **Fixed Income** credit analysis asks you to compute leverage and coverage ratios from the
  same statements.

Learn FSA last and you spend three topics faking a foundation you do not have. Learn it first and
those topics get easier rather than harder.

It is also the topic with the best front-loading economics: 11–14% of the exam on its own, and it
**decays slowly**, because it is procedural rather than definitional. What you learn in week 1 is
still there in month 5.

> **Study the modules in order.** This topic is genuinely sequential — LM4 (cash flows) is
> unworkable without LM2 and LM3, and LM11 (ratios) consolidates everything before it. Do not
> cherry-pick.

## The formulas this topic lives on

Six things from this topic must be automatic before you leave it. Everything else can be re-derived.

```
1. Basic and diluted EPS, including the treasury stock method and the antidilution test
2. Indirect CFO: NI + non-cash − gains + (WC: assets opposite, liabilities with)
3. FCFF = CFO + Interest(1−t) − Capex        FCFE = CFO − Capex + Net borrowing
4. FIFO inventory = LIFO inventory + LIFO reserve;  FIFO COGS = LIFO COGS − ΔLIFO reserve
5. Cash conversion cycle = DOH + DSO − Days of payables
6. ROE (5-part) = (NI/EBT)(EBT/EBIT)(EBIT/Rev)(Rev/Assets)(Assets/Equity)
```

## Topic wrap-up

Before you tick this topic complete and move to Quantitative Methods:

- [ ] All 12 modules ticked, with their **Done when** lists genuinely cleared
- [ ] I can build a cash flow statement by **both** the direct and indirect methods from a set of
      statements and balance-sheet movements
- [ ] I can convert a LIFO reporter to FIFO — inventory, COGS, net income, and equity
- [ ] I can run a five-part DuPont and explain which component drove a change in ROE
- [ ] I can compute every ratio in LM11 without looking at the formula sheet
- [ ] I have completed **100+ FSA questions** and logged every miss in `trackers/weak-areas.md`
- [ ] I can name five accounting warning signs and explain what each one predicts

**Day 20 checkpoint.** If more than two of these are unticked, spend a day clearing them before
starting QM. FSA is the foundation — a shaky foundation costs you in three later topics, not one.
